\# 💰 TaxMate – AI-Powered Tax Calculator



TaxMate is a full-stack web application that helps users calculate taxes based on their salary and provides basic tax awareness using AI-driven logic.



\---



\## 🚀 Features



\* 💡 Salary-based tax calculation

\* ⚡ Fast API using Flask

\* 🎯 Clean and responsive UI (React + Vite)

\* 🔗 Frontend–Backend integration

\* 📊 Real-time results



\---



\## 🛠️ Tech Stack



\### Frontend



\* React (Vite)

\* Tailwind CSS



\### Backend



\* Flask (Python)

\* REST API



\---



\## 📁 Project Structure



```

Taxmate-A-app-for-tax/

├── frontend/     # React frontend
```

\## ⚙️ How to Run Locally



\### 1. Clone the repository



```

git clone https://github.com/AbdulSami326/Taxmate-A-app-for-tax.git

cd Taxmate-A-app-for-tax

```



\---



\### 2. Run Backend



```

cd backend

python -m venv .venv

.venv\\Scripts\\activate

pip install -r requirements.txt

python app.py

```



Backend runs on:



```

http://127.0.0.1:5000

```



\---



\### 3. Run Frontend



Open new terminal:



```

cd frontend

npm install

npm run dev

```



Frontend runs on:



```

http://localhost:5173

```
